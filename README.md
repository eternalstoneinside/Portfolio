# Dmytro Orlenko — Frontend Portfolio

A bilingual portfolio presenting selected frontend projects, technical skills, and contact channels.

[Live demo](https://eternalstoneinside.github.io/Portfolio/)

## Overview

The portfolio is a dependency-free static site focused on quick loading, clear project storytelling, and a consistent visual identity. It supports English and Ukrainian content, responsive project cards, and lightweight interface animation.

## Highlights

- English and Ukrainian interface
- Responsive layouts for mobile, tablet, and desktop
- Project cards with visual previews and direct links
- Lightweight animations without runtime dependencies
- PWA metadata, favicon, and social preview assets
- Semantic HTML and keyboard-friendly navigation

## Tech stack

HTML5 · CSS3 · JavaScript · Git · Figma

## Run locally

```bash
git clone https://github.com/eternalstoneinside/Portfolio.git
cd Portfolio
python -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Project structure

```text
index.html          Page structure and content
css/main.css        Layout, themes, and responsive styles
js/main.js          Translations and interactions
img/                Project previews and interface assets
site.webmanifest    PWA metadata
```
